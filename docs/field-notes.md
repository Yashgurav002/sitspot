# Field notes

Real visits only, one entry per visit, written the same evening. Nothing here is invented or staged. If a visit was bad, write that down. If a bird was detected but not seen, say so.

Copy the template below for each new entry, newest at the top.

---

## Template

### YYYY-MM-DD — <spot name>

| | |
| --- | --- |
| **Invitation** | call / push · rang at HH:MM · window HH:MM–HH:MM · score 0.xx |
| **Reason given** | the one-sentence reason stored with the invitation |
| **Factors** | p_rich · comfort · tide_fit · light_bonus · novelty · availability |
| **Response** | accepted / declined / no answer · left at HH:MM · arrived HH:MM · left HH:MM |
| **Rating** | 1–5 |

**What happened.** 2–5 plain sentences: conditions on arrival, whether the call's reasons held up (tide, heat, light, AQI), anything surprising.

**Birds**

| Species | Detected (BirdNET, max confidence, count) | Seen by me | Notes |
| --- | --- | --- | --- |
| | | yes / no / heard only | |

**Honest notes.** What was wrong or annoying: a false detection, a bad time to call, a battery drain (% start → end), the app getting in the way, a safety concern.

**Evening note.** Paste the generated field note, and say whether it was the model or the `template`.

**Footage.** File names / links, if any.
